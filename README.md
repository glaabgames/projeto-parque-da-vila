# Parque Vivo

## Sobre o projeto

O Parque Vivo é um aplicativo mobile desenvolvido com o objetivo de contribuir para a revitalização do Parque da Vila São João. A proposta é facilitar o acesso dos visitantes às informações do parque, permitindo explorar os espaços disponíveis e realizar reservas de áreas de lazer.

O projeto busca incentivar a utilização dos espaços públicos, proporcionando uma experiência mais organizada, acessível e prática para os visitantes.

## Objetivo

Desenvolver uma solução tecnológica que auxilie na organização e utilização dos espaços do parque, facilitando a exploração, o agendamento e o acompanhamento das reservas.

## Funcionalidades

- **Tela inicial:** apresentação e acesso às funcionalidades do aplicativo.
- **Login:** acesso à conta do usuário.
- **Cadastro:** criação de uma nova conta.
- **Mapa:** visualização e exploração dos espaços do parque.
- **Reservas:** consulta e seleção dos espaços disponíveis.
- **Agendamento:** realização de reservas dos espaços de lazer.
- **Histórico:** acompanhamento das reservas realizadas.

## Tecnologias utilizadas

- **React Native:** desenvolvimento da interface mobile.
- **JavaScript:** linguagem utilizada na implementação das funcionalidades.
- **Expo:** ambiente de desenvolvimento e execução do aplicativo.
- **Git e GitHub:** controle de versão e gerenciamento do código-fonte.
- **API REST:** comunicação entre o aplicativo e o servidor para operações de autenticação e cadastro.

## Estrutura do projeto

O projeto está organizado em componentes, com cada tela separada em seu próprio arquivo para facilitar a manutenção e o desenvolvimento.

- `App.js`: componente principal e gerenciamento da navegação entre telas.
- `screens/00-splash.js`: tela de boas-vindas.
- `screens/01-login.js`: tela de login.
- `screens/02-cadastro.js`: tela de cadastro.
- `screens/03-home.js`: tela inicial.
- `screens/04-mapa.js`: mapa do parque.
- `screens/05-reservar.js`: tela de reservas.
- `screens/06-historico.js`: histórico de reservas.
- `screens/07-agendamento.js`: tela de agendamento.

## Como executar o projeto

1. Instale o Node.js e o Expo.
2. Clone o repositório do projeto.
3. Abra a pasta do projeto no terminal.
4. Execute o comando:

`npm install`

5. Inicie o aplicativo com:

`npx expo start`

6. Utilize o Expo Go para visualizar o aplicativo no dispositivo móvel.
